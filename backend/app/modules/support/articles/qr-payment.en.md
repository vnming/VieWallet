Open **Scan QR** to scan a shop's or a friend's code. If the browser has no camera support, type the 16-character code under the QR.

## Verified shops

A shop's code shows a **Verified** label and the shop name. Only VieWallet codes open.

## Requests

Open **Request money** to create a request with a QR, optionally addressed to an e-mail or wallet number.
